## 2. Tecnologías utilizadas
- **Lenguajes:** TypeScript
- **Frameworks:** React + MapLibre GL (frontend y mapa) · Node.js + Express (backend/API propio)
- **Base de datos:** PostgreSQL + PostGIS (contenedor Docker)
- **Cloud / Infraestructura:** Docker + Docker Compose · Oracle Cloud — VM Always Free (x86, 1GB).

## 3. Instrucciones para ejecutar el proyecto localmente
```bash
# 1. Clonar el repositorio
git clone https://github.com/ElegantCharles/PetMap.git
cd PetMap

# 2. Variables de entorno (copiar el ejemplo y completar)
cp .env.example .env

# 3. Levantar todo con Docker (frontend + backend + base de datos)
docker compose up --build
```
